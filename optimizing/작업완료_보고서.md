## 9. 아키텍처 변경 요약

### AS-IS (500개 스케일)
```
main.py → MassCollector → 6단계 순차 실행 → SQLite → S3
                          (단일 프로세스, glob 기반)
```

### TO-BE (5,000개 스케일)
```
main.py (run_id 자동생성)
  → PipelineOrchestrator
      │
      ├─ [Crawl]     AsyncCrawlerPool(16w) + Registry + 카테시안 500키워드
      ├─ [Download]   ParallelDownload(12w) + retry 3 + 5MB/s + DiskPolicy
      ├─ [Process]    UnifiedVideoProcessor(1-Pass) / GPU 6-Stream / CPU Pool
      ├─ [Quality]    BatchEvaluator (vectorized, threshold 50)
      ├─ [Upload]     S3 ParallelUpload(8w) + --delete-local
      └─ [Cleanup]    DiskPolicy.cleanup_after_upload()

      PostgreSQL (pool_size=20) ←→ Redis (registry + cache + queue + DLQ)
      Dashboard: DB 쿼리 + SSE + RunsPage + DedupStats
      Monitoring: 6 알림규칙 + 5 메트릭 + Airflow DAG
```
